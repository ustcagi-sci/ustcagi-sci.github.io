# AI for Science 全站配色对齐设计

## 目标

以“科学推演智能体”页面为唯一视觉基准，将全站从红色、棕色和暖米色混合风格统一为深海军蓝、亮蓝、青蓝、浅蓝与白色构成的科研视觉体系。只调整颜色、阴影和边框色，不改变页面内容、信息架构、图片、交互或响应式布局。

## 视觉策略

采用“共享冷色基座 + 页面层级差异”的方案：

- 全站基础令牌使用深海军蓝 `#061f45`、主蓝 `#0b5fc6`、青蓝 `#59b7ef`、浅蓝 `#edf7fc`、冷灰蓝背景 `#f4f7f9` 与白色表面。
- 普通内容页继续使用浅色阅读界面，英雄区改为白色至浅蓝渐变，卡片使用白色表面和冷蓝边框，主按钮、导航激活态与标题下划线统一使用主蓝。
- “科学推演智能体”页保留现有深蓝渐变英雄区，作为全站最强视觉锚点；其内部原有红色输入标签和研究者轨道统一改为浅蓝与深蓝。
- Mind2Report 保留独立排版与论文插图，但其棕色变量、暖色网格、卡片和页脚改用同一套蓝色令牌。
- 全站页脚统一为深海军蓝背景、白色标题、冷灰蓝正文和青蓝链接。

## 可访问性与交互

- 正文与白色或浅蓝背景保持高对比度；主按钮使用白字配主蓝背景。
- 焦点环、悬停边框与激活态使用蓝色透明度，不依赖红/绿来表达状态。
- 不新增动画；继续尊重现有 `prefers-reduced-motion` 规则。

## 验证标准

- 自动检查共享样式和 Mind2Report 样式中的核心令牌与页脚色值一致。
- 自动检查旧的红色/棕色主色不再出现在生产 CSS 中。
- 现有国际化、导航、页脚、链接和页面结构检查全部通过。
- 在首页、各子页面与 Mind2Report 上进行桌面和移动视口渲染检查，确认无水平溢出、不可读文字或异常控制台错误。

## 范围边界

不修改品牌 Logo、论文图片、PDF、文案、导航顺序、URL、SEO 内容或页面布局。用户已有的未跟踪文档不纳入提交。
