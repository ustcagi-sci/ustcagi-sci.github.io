# AI for Science 开源项目页面设计

## 目标

在现有 USTC-AGI · AI for Science 网站中新增双语“开源项目”页面，集中展示已经在站内出现、且官方 GitHub 仓库仍公开可访问的科研基础设施、智能体、评测与数据工具。页面必须沿用全站共享视觉、导航、国际化、SEO 和统一页脚规范。

## 方案比较

1. **平铺仓库目录**：实现最简单，但项目之间缺少关系，容易退化为链接集合。
2. **科研工作流分组目录（采用）**：按“证据与技能基础设施”“研究智能体”“评测与科研工具”组织项目，既能快速浏览，也能解释它们如何共同服务科研智能。
3. **实时 GitHub 数据面板**：可以展示 Star、更新时间和语言，但需要运行时 API，数值波动快、存在限流，并偏离当前纯静态站点架构。

采用第二种方案，保持静态、稳定、可维护，不展示容易过期的 Star 或提交计数。

## 信息架构

### 顶部横幅

复用 `ref.css` 的标准 `hero > hero-content` 结构，标题为“开源项目”，副标题说明项目覆盖证据访问、学术检索、研究智能体、过程评测与科学文档理解。

### 生态概览

用三个概览卡说明页面的组织逻辑：

- Evidence & Skills：Lewen API、Academic Search
- Research Agents：PaperScout、Mind2Report
- Evaluation & Tools：PaperArena、ChemTable

### 项目目录

正文使用三组双列卡片，每组两个项目：

1. **证据与技能基础设施**
   - Lewen API：科学文献、元数据、引用关系、开放全文与多模态证据接口。
   - Academic Search：面向 Agent Runtime 的多源学术检索、查询扩展、元数据补全与引用追踪技能。
2. **研究智能体**
   - PaperScout：围绕科研问题自主规划检索与证据筛选路径的论文搜索智能体。
   - Mind2Report：通过意图澄清、记忆增强检索与迭代综合生成可追溯报告的深度研究智能体。
3. **评测与科研工具**
   - PaperArena：面向工具增强智能体跨论文检索、证据整合与推理能力的评测基准。
   - ChemTable：评测多模态模型理解真实化学表格结构、符号与语义能力的基准。

每张卡包含稳定的功能定位、技术标签和官方链接。论文或项目主页仅在站内已有可核验地址时提供。页面不宣称所有公开仓库使用同一种许可证；使用和二次开发以各仓库当前 License 与文档为准。

### 共建入口

末尾提供 GitHub 组织与邮件联系入口，说明可围绕问题反馈、工具集成、评测扩展和研究合作参与共建。

## 全站接入

- 在六个现有双语主页面和新页面的导航中，将“开源项目 / Open Source”放在 “Science of AI” 与“论文列表 / Publications”之间。
- 新页面加入 `sitemap.xml`、SEO 元数据、README 站点结构说明和静态验证页面清单。
- Mind2Report 保留其独立的论文项目页内部导航，但统一页脚文案与七个主页面同步加入开源项目合作范围。
- 不改动现有页面正文、项目卡片或项目论文页。

## 视觉与响应式

- 使用现有白色至浅蓝网格横幅、深海军蓝标题、主蓝强调色、白色卡片和冷蓝边框。
- 项目卡使用双列布局，卡片顶部以类别和语言标签建立层级，底部链接使用现有胶囊按钮语汇。
- 1024px 以下检查导航换行；760px 以下项目卡改为单列，所有外链按钮保持可触控尺寸。
- 不新增图片或动画，避免无必要的装饰和资源负担。

## 验证标准

- `projects/index.html` 具有完整中英文翻译、标准横幅、六张项目卡、三组目录、统一页脚和安全外链属性。
- 七个双语主页面的导航键、顺序、链接和激活态一致。
- `sitemap.xml`、README、SEO 元数据和站内链接验证包含新页面。
- 桌面和移动视口无水平溢出、导航遮挡或控制台错误；语言切换后标题、导航和项目文案正确更新。
- 用户已有未跟踪 Markdown 文档不修改、不暂存、不提交。
